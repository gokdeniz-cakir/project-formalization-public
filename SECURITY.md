# Security policy

Please do not use GitHub issues for suspected vulnerabilities in Project
Formalization or in a third-party project studied here. Use the affected
project's published security-reporting channel instead.

This repository intentionally contains only already-public case studies. Do
not add unpublished traces, exploit material, private issue links, target
source checkouts, investigator prompts, or disclosure correspondence. Run
`python scripts/audit-publication.py` before opening a pull request or
deploying the site.
