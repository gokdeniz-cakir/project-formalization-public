# Evidence standard

A production-issue claim needs a pinned upstream revision, a concrete witness,
a fresh unmodified replay, a useful negative control, and checker-sanity
evidence. Formal models must state their bounds and assumptions. A model-only
counterexample is not silently promoted to a production vulnerability.

Public case notes also state what was not established: remote reachability,
exploitability, code execution, and confidentiality impact are separate claims
that require separate evidence.
