# Workflow

Project Formalization uses a coordinator to freeze a source pin, bounded
component, and safety properties. Two investigators then work independently:
one searches for a suspected violation and the other evaluates the same
properties without an expected result. A hostile review challenges the
preserved evidence only after each arm is sealed.

The coordinator compares evidence rather than confidence. A public case is
published only after its underlying issue is already disclosed and the artifact
set has passed the repository publication gate.
